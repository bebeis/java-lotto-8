# java-lotto-precourse

## 비즈니스 로직 정리

- 구매 가능 여부를 판단한다.
- 발행할 로또의 개수를 계산한다.
- 자동 번호 로또를 발행한다.
- 당첨 번호와 비교하여 로또의 등수를 계산한다.
- 총 수익률을 계산한다.

## 유즈케이스 정리

- 구매 가능 여부를 판단한다.
- 발행할 로또의 개수를 계산한다.
- 로또를 N장 발행한다.
- 당첨 번호를 입력받는다.
- 보너스 번호를 입력받는다.
- 티켓별 로또 등수를 계산한다.
- 총 수익률을 계산한다.

## 시스템 요구사항

### 입력

- 로또 구입 금액을 입력받는다.
    - 입력 예외 상황
        - 숫자가 입력되지 않은 경우
        - 너무나 큰 값이 입력된 경우
- 당첨 번호를 입력받는다. (쉼표를 기준으로 구분한다.)
    - 입력 예외 상황
        - CSV에 빈 값이 존재하는 경우
        - 숫자가 아닌 값이 입력된 경우
        - 너무나 큰 값이 입력된 경우
- 보너스 번호를 입력받는다.
    - 입력 예외 상황
        - 숫자가 아닌 값이 입력된 경우
        - 너무나 큰 값이 입력된 경우

### 동작

- 로또 구입 금액에 해당하는 만큼 로또를 발행한다.
- 로또 번호는 랜덤으로 생성된다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 계산한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
    - 명확한 예외 유형을 사용한다.

### 출력

- 발행한 로또 수량 및 번호를 출력한다.
    - 로또 번호는 오름차순으로 정렬하여 보여준다.
- 당첨 내역을 출력한다.
- 수익률을 출력한다.
    - 소수점 둘째 자리에서 반올림한다.
- 예외 상황 시 에러 문구를 출력해야 한다
    - 에러 문구는 "[ERROR]"로 시작해야 한다.

## 도메인 규칙

### 구매 금액

- 1000원 단위로 나눠 떨어져야 한다.
- 1000원 이상이어야 한다.

### 로또 번호

- 숫자의 범위는 1~45이다.

### 로또

- 로또는 6개의 숫자로 구성된다.
- 로또 내의 로또 번호는 중복될 수 없다.

### 로또 가격

- 로또 1장의 가격은 1000원이다.

### 당첨 번호

- 중복되지 않는 숫자 6개와 보너스 번호로 구성된다.
- 보너스 번호는 6개의 기본 숫자와 중복될 수 있는가?
    - 판단: 불가능하다.

### 등수

- 1등: 6개 번호 일치 / 2,000,000,000원
- 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
- 3등: 5개 번호 일치 / 1,500,000원
- 4등: 4개 번호 일치 / 50,000원
- 5등: 3개 번호 일치 / 5,000원
